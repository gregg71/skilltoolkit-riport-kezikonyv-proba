# SkillToolkit Analitika/Riport modul

Felhasználói kézikönyv kattintható tartalomjegyzékkel, nagyítható képekkel és beépített videólejátszókkal.

Az index.html mellé a tárhelyen található MP4-fájlok is szükségesek. A videók a megfelelő fejezetben, helyben játszhatók le; egyszerre egy videó szól.

A TANF_TSTK12 v0.8 segédlet 45 exportált diáját tartalmazza, a kiegészítő súgókkal együtt. 71 képmegjelenés, 67 különböző kép és 40 különböző videó (21 riportbemutató, 19 súgóvideó) szerepel benne. A többször hivatkozott videókat a megfelelő helyeken ismét megjelenítjük, de fájlonként csak egyszer tároljuk.

A forrás szövege megmaradt. A riporttípusokra utaló hibás 3. fejezet hivatkozást a 4. fejezetre javítottuk, és visszaállítottuk a három, exportból elveszett videóugrás célját a forgatókönyv alapján. A lejátszás önálló, nem küld adatot az eredeti képzési rendszerbe. A tananyagban nincs teszt vagy vizsga; a teszttípusokat bemutató videók súgóvideók.

Forrás: SkillDict Zrt. Az eredeti tartalom jogai a jogosultaknál maradnak.
